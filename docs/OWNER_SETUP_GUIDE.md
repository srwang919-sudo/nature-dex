# 去大自然里上线配置清单

不要把密钥、密码、证书、身份证件或用户照片发送到聊天、文档、代码仓库或截图。本清单中的“我”只需要你提供非敏感的 CloudBase 环境 ID、已完成的控制台步骤和测试结果。

## 你完成：账号与微信后台

- [ ] 登录 [微信公众平台](https://mp.weixin.qq.com)，完成主体认证、管理员与开发者权限分配。
- [ ] 在「开发 → 开发管理 → 开发设置」确认 AppID；在「开发 → 开发管理 → 开发版本」添加体验成员。
- [ ] 在「开发 → 开发管理 → 开发设置 → 服务器域名」按实际后端填写 HTTPS 域名；不使用临时个人域名。
- [ ] 在「设置 → 基本设置 → 服务类目」选择与你实际业务相符的类目；不描述为官方鉴定或实时物种雷达。

## 你完成：CloudBase

- [ ] 打开 [CloudBase 控制台](https://console.cloud.tencent.com/tcb)，新建生产环境，记录环境 ID（可安全发给我）。
- [ ] 在「数据库」创建 `observations`、`gifts`、`cleanupQueue`；为 `gifts.idempotencyKey`、`cleanupQueue.observationId` 建索引。
- [ ] 在「云存储」将原图和生成图设为私有：仅创建者可读写；不要公开列目录或原图 URL。
- [ ] 在「云函数」依次部署 `recognizeObservation`、`generateIllustration`、`claimGift`、`deleteObservationAssets`：对每个函数右键「上传并部署：云端安装依赖」。
- [ ] 在每个函数的「配置 → 环境变量」内填写下表。只在控制台填写，永不发给我。

| 函数 | 必填变量 | 可选变量 | 来源 |
| --- | --- | --- | --- |
| recognizeObservation | `BAIDU_API_KEY`、`BAIDU_SECRET_KEY` | 无 | 百度智能云应用凭据 |
| generateIllustration | `DASHSCOPE_API_KEY` | `DASHSCOPE_API_HOST`、`DASHSCOPE_MODEL` | 阿里云百炼工作空间；默认 host 为 `https://dashscope.aliyuncs.com`，默认 model 为 `wanx2.1-imageedit` |
| claimGift | 无 | 无 | CloudBase 数据库事务 |
| deleteObservationAssets | 无 | 无 | CloudBase 存储与清理队列 |

## 你完成：百度与万相服务

- [ ] 打开 [百度智能云](https://cloud.baidu.com)，创建图像识别应用，开通植物识别、动物识别及组合图像识别所需权限；阅读计费、并发与数据处理条款。
- [ ] 在百度应用内创建凭据，并仅复制到 CloudBase 的 `BAIDU_API_KEY`、`BAIDU_SECRET_KEY` 环境变量。
- [ ] 打开 [阿里云百炼](https://bailian.console.aliyun.com)，在北京工作空间开通万相图像编辑模型；确认服务地域、内容安全与数据处理条款。
- [ ] 将百炼 API Key 仅写入 `DASHSCOPE_API_KEY`。若工作空间提供不同网关，填 `DASHSCOPE_API_HOST`；模型改变时填 `DASHSCOPE_MODEL`。

## 我收到非敏感信息后完成

- [ ] 你提供 CloudBase 环境 ID 后，我在 `app.js`/客户端配置中写入非敏感 `envId` 和明确服务开关；默认开关保持关闭，直到你完成上述验证。
- [ ] 我核对四个函数部署名称、客户端状态文案与数据库字段；不会读取、请求或保存你的任何密钥。
- [ ] 我协助用测试照片验证：已识别、需用户确认、未知、服务失败。结果是候选建议，不承诺精准识别。

## 你完成：隐私、体验与审核

- [ ] 在微信后台「设置 → 隐私与安全 → 用户隐私保护指引」勾选并说明：相机、相册、私有云存储、物种候选、可选图生图、微信身份；默认不收集精确位置。
- [ ] 写清每项用途、触发时机、保存期限、第三方服务、撤回同意和删除渠道；图生图必须单独征得同意。
- [ ] 使用两名体验成员测试相机/相册拒绝后恢复、断网、未知物种、低置信度确认、删除、导出和赠送未开放状态。
- [ ] 在「开发 → 开发管理 → 开发版本」上传体验版、按真实路径生成审核截图与说明；审核材料不得用概念图代替当前功能。

## 失败排查

| 现象 | 先检查 |
| --- | --- |
| 显示“真实鉴别尚未接通” | 环境 ID、服务开关、函数部署状态；不要在客户端放密钥 |
| 显示 `not_configured` | 对应函数的必填环境变量名称是否完全一致 |
| 显示 `unknown` | 照片可能不含可映射物种；保留草稿并手动确认或换图 |
| 图生图失败 | 是否已同意上传、百炼模型/区域是否开通、内容安全是否拒绝；卡背会保留本地插画 |
| 保存相册失败 | 在系统或微信设置中重新允许“保存图片”，再回到卡片重试 |
| 审核被拒 | 按反馈在体验版复现并回归；不承诺审核一定通过 |

当前版本不加载本地 `@font-face`：部分微信开发者工具会把本地字体路径标记为错误。标题使用设备已有的 `Kaiti SC / STKaiti / PingFang SC` 字体栈，正文为系统苹方，数字使用 `DIN Alternate / PingFang SC`。历史生成的 WOFF2 子集保留在源码资产中供后续评估，但已从发布包精确排除；不要把它重新作为本地字体路径接入。不要排除正在使用的照片或七种卡背插画；每次替换资源后重新检查包体和真机页面。
