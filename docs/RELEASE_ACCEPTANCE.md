# 去大自然里发布验收矩阵

每一行必须以当前构建、真实设备或对应线上环境的证据验收。通过标准中的“截图/录屏”必须可追溯到构建号、设备和日期；无证据即未通过。

| 范围 | 场景 | 通过标准 | 必需证据 |
| --- | --- | --- | --- |
| 三 Tab | 探索、博物志、我的互相切换 | 只有三个一级 Tab；拍摄从探索主动作进入；返回保持正确 Tab；无第四个拍摄 Tab | 三个首屏截图与切换录屏 |
| 探索 | 零收藏与有收藏 | 山林封面、唯一主相机、相册/附近入口可用；今日收集只含当天本地记录；空态不造数 | 两种数据状态截图 |
| 博物志 | 浏览、搜索、筛选、详情 | 筛选在博物志次级层，不压探索首屏；只显示本地卡/资料 | 录屏与本地数据对照 |
| 我的 | 本地记录与管理 | 仅显示真实物种数、卡数、观察日数、笔记、草稿；无假积分、订阅、身份或同步 | 截图与存储数据对照 |
| 附近生境 | 未授权定位 | 展示生境指南，不调用或展示他人位置、精确地点、距离、热度或不存在的设置开关 | 断言日志与截图 |
| 正面卡 | 七物种与旧卡 | 保留真实照片、双层边框、编号、工艺、中文/拉丁名；每张固定五个星位，旧 1–4 星不被升级 | 七卡截图和迁移数据测试 |
| 背面卡 | 七物种、长名称、最长保护文案 | 每种显示正确且可辨的专属插画；一页无滚动；一个短要点、生境季节、保护、编号日期完整可读 | 七张截图与最坏字段截图 |
| 插画降级 | 缺失或解码失败资产 | 不显示其他物种图；显示纸张/共享线稿降级，正文不遮挡 | 模拟缺失资产截图 |
| 开牌 | 点按、按住、取消、重复触发 | 封签静候、纸封裂开、卡片抬起、落版揭晓顺序正确；取消归位；只创建一张卡 | 完整录屏与重复点按测试 |
| 低动效 | 设置开启 | 开牌与翻面直接切换，无持续高光/倾斜，所有内容和操作可用 | 前后对比录屏 |
| 3D 查看 | 详情进入、打开、关闭 | 详情默认没有覆盖层；显式打开后全屏纯净；关闭回原详情，不混入底层可点控件 | 录屏 |
| 翻面手势 | 轻点、拖动、touchcancel | 轻点翻面；超过 8px 不误翻；取消归位；文字不镜像 | 手势录屏 |
| 相机与相册 | 首次拒绝/允许、换图 | 权限说明准确；拒绝可恢复；换图使旧识别结果失效 | 真机录屏 |
| 鉴别 | 未配置、可确认、低置信度、未知、超时 | 未配置明确 unavailable；低置信度须确认；未知保留草稿；超时可重试；不虚构置信度 | 云函数日志和界面截图 |
| 照片导出 | 正常、低清晰度、解码失败、文件删除、离页 | 正常导出完整照片和对应插画；低清晰度提示；其余情况不产生粉红、空白、旧缓存或成功提示 | 相册成品与失败录屏 |
| 分享 | 资料分享与含照片导出 | 资料分享无私照、笔记、卡号、地点或来源；含照片导出有明确确认 | 分享接收端截图 |
| 图生图 | 同意、成功、超时、拒绝 | 每次上传前单独同意；生成只作装饰；失败保留原卡；供应商错误不泄露凭据 | 同意记录、云函数日志、截图 |
| 赠送 | 未登录、同意、并发领取、过期 | 未开放时不假成功；开放后双方同意，同一礼物只领取一次，私人数据不转移 | 双账号录屏与事务日志 |
| 删除 | 本地、云端、派生图、断网 | 删除请求覆盖照片、生成图和记录；失败显示待重试而不假称完成 | 存储核对、离线/重连录屏 |
| 安全与隐私 | 权限、密钥、访问控制 | 凭据只在云函数密钥管理；私有照片不可被他人直接读取；隐私指引与实际一致 | 配置截屏（打码）与账号测试 |
| 性能与包体 | 低端 Android、冷启动、资源 | 首屏可交互、动画不掉帧到不可用；主包符合微信当前限制；资源清单说明大文件来源 | 真机录屏、构建包报告 |
| 编译回归 | JavaScript、WXML、WXSS、原生测试 | 全量 Node 检查、现有 native 测试、官方 WXML/WXSS 编译全部通过 | 命令输出存档 |
| 微信审核 | 提交材料 | 类目、备案（如适用）、域名、隐私、截图、审核路径均与当前构建一致 | 审核提交记录 |
