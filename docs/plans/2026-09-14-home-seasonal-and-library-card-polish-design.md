# 首页当季推荐与博物志卡片打磨设计

## 目标

以最新两张参考图为唯一视觉依据，完成发现首页的季节推荐、收藏页的案例卡与章节格，以及三条入口的真实路由。现有识别、揭晓、翻面、3D、导出和本地数据语义不变。

## 首页

首页保留既定结构：水墨山景、大圆拍摄入口、相册/附近入口、今日四格、当季双卡、三 Tab。当前轮只细化下半区：

- “当季推荐”为两列卡片，每张约 `329×285rpx`；图片高 `154–162rpx`，图片贴齐卡片上边及左右边；文本位于图片下方。
- 固定展示两条编辑内容：`春日观察 / 万物复苏的相遇` 与 `水边的生灵 / 发现身边的野趣`。右侧使用 chevron；不显示拉丁名、栖息地或季节三行元数据。
- 标题右侧为可点击的 `更多 ›`，进入对应内容页（当前使用已有附近/季节内容承载页）。
- 相册入口去收藏页；附近入口必须去真实附近页，而不是笔记页；只有拍一张进入拍摄页。
- 所有可点元素具有压下反馈，至少 `88rpx`（约 44px）有效点击高度。

## 收藏页

- 案例卡横向区域每张 wrapper 固定宽 `278rpx`、高 `389rpx`，保持 `5:7`，内部 `collectible` 撑满。
- 横向滚动容器高度至少 `430rpx`，确保卡面、内置示例标记均未裁切；一屏露出约 2.3 张卡。
- 删除卡下重复的“示例卡”文字，只保留区块的说明和 collectible 内部的示例标记。
- 真实收藏网格同样按 `5:7`，不将卡片压成矮矩形。
- 章节九格显示已发现物种缩略图；未发现单元使用柔和占位，不使用 `●/○`。

## 状态与可访问性

- 示例卡永远不计入真实收藏、章节、经验或打卡。
- 详情、3D、翻面、返回流程保持；列表页不在刷新时重置滚动位置。
- 图片加载失败继续显示“原图不可用”回退。

## 验收

静态断言覆盖精确尺寸、文案、路由与无重复标签；运行时覆盖 legacy 示例存储下收藏页能初始化且只把真实卡点亮章节。全量 Node 测试、JS 语法与官方 WXML/WXSS 编译均通过；不上传或预览。
