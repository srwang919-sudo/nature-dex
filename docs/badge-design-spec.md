# 徽章系统设计规范

> 版本：v0.1.4 ｜ 组件：`native/components/nature-badge` ｜ 模型：`native/lib/badge-model.js`

## 一、结构：金属外环 + 珐琅内圈 + 手绘图案

```
┌─ 金属外环（斜向渐变 + 高光反射带 + 内描边）
│  ┌─ 珐琅内圈（径向渐变 + 颗粒纹理 + 内阴影）
│  │  └─ 手绘图案（currentColor 线稿，不绑定单一金属色）
```

- 高光用 `.enamel::after` 的斜向 `linear-gradient`（125°），让金属有反光方向感
- 珐琅纹理用 `.rim::before` 的 9rpx 网点 `radial-gradient`，透明度 0.14，模拟珐琅颗粒
- 图案的实心点缀统一用 `currentColor` + `opacity:.5`，不再硬编码金色，避免换等级时图案串色

## 二、等级：铜 → 银 → 金 → 铂

等级由达成难度自动推导（`tierOf(target)`），金属色与珐琅色**双重区分**：

| 等级 | 触发条件 | 金属 | 珐琅 | 现有徽章 |
|---|---|---|---|---|
| 铜 copper | target 1–3 | `#B87333` | 苔藓绿 `#4A7C59` | 初识自然、三叶档案、飞羽来信、微观访客、重逢之约、细察之心、山野行者、拼图成画 |
| 银 silver | target 4–9 | `#C0C0C0` | 湖蓝 `#4A7A96` | 四时相逢、守护目光 |
| 金 gold | target 10–19 | `#E8B84B` | 深棕金 `#6B5535` | 风物成册 |
| 铂 platinum | target ≥20 | `#D8DEE2` | 深青 `#3F5A5F` | 博物志人 |

组件接受 `tier` 属性；未传时按 `target` 用 `tierOf` 推导，保证视觉与模型永不脱节。

## 三、状态

| 状态 | 表现 |
|---|---|
| 未解锁 `locked` | 灰度 0.9 + 透明度 0.7 + **虚线轮廓**：保留形状与等级暗示，让"还没拿到的"清晰可见 |
| 已获得 `earned` | 完整金属/珐琅 + 外阴影 + 内高光描边 |
| 大尺寸 `large` | 加粗内描边与内阴影，用于预览弹层（420rpx） |

## 四、尺寸

由父级容器决定，令牌出口在 `app.wxss`：`--badge-sm 64rpx` / `--badge-md 96rpx` / `--badge-lg 192rpx`。
实际使用：图鉴网格 112rpx、预览弹层 420rpx。

## 五、收集引导

- 勋章区标题下增加**总进度条**：`已获得 N / 12`，填充色用 `--color-accent`（暖阳金）
- 每枚徽章名称后带**等级标签**（铜/银/金/铂），标签配色随等级变化
- 未解锁项显示 `进度 / 目标 · 探索中`，状态文字降为三级文字色
- 点击任意徽章打开详情弹层：大图 + 已获得/尚未获得 + 获取条件 + 当前进度

## 六、解锁动画（reveal）

原实现只是 `scale(.94→1)` + 淡入。升级为：

- `badge-flip`：3D 翻转入场 `rotateY(-90deg) → 12deg → 0`，带轻微过冲
- `badge-burst`：伪元素光效爆发，径向暖金光从 0.4 放大到 1.55 倍并淡出
- `reduce-motion` 与系统 `prefers-reduced-motion` 下全部关闭，直接静态呈现

## 七、无障碍

徽章本体是纯装饰（`aria-hidden="true"`），可点击性由外层网格项承担（`aria-role="button"` + 完整 aria-label），读屏不会念出无意义的图形节点。
