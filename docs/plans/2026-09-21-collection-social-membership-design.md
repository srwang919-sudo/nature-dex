# 方案 C：真实收藏、自然勋章与社交会员设计

日期：2026-09-21。状态：用户已批准设计；本文不代表功能已实现或服务已开通。

## 1. 决策与范围

以「拍一张 → 鉴别 → 确认物种 → 自动彩绘与科普 → 成功入册」为主线，减少首页任务与操作选择。保留首页、图鉴、我的三栏结构。本设计替代此前“类别成就并列十二物种徽章”的获得规则，合并为一套十二枚条件型自然勋章；不删除旧资产，不将旧奖励记录或案例虚构为新条件已满足。

现有七张案例的原始数据与资产保持不变，不计入任何真实收藏、等级、勋章、足迹和社交统计。图鉴只显示真实收藏；如保留案例教学，应位于帮助中的独立案例入口，明确标注示例而非用户记录。

## 2. 十二枚自然勋章

统一通过同一个条件模型计算进度、解锁和首次反馈，不在不同页面维护不同阈值。仅采用成功入册的真实记录及可验证的用户主动行为。

| 名称 | 解锁条件 | 计数口径 |
|---|---|---|
| 初识自然 | 收藏 1 种 | 去重 canonical speciesId |
| 三叶档案 | 收藏 3 种植物 | 已确认植物类别，按物种去重 |
| 飞羽来信 | 收藏 3 种鸟 | 已确认鸟类类别，按物种去重 |
| 微观访客 | 收藏 3 种虫 | 已确认昆虫类别，按物种去重 |
| 重逢之约 | 同一物种观察 3 次 | 3 个不同成功记录 ID；重试不重复计数 |
| 细察之心 | 写下 3 篇笔记 | 3 条真实记录各有非空笔记；编辑同篇不累加 |
| 四时相逢 | 在 4 个日期相遇 | 成功观察的 4 个不同本地日期，不要求四季 |
| 山野行者 | 主动保存 3 个地点 | 真实记录中 3 个不同地点标识；重复地点不累加 |
| 风物成册 | 收藏 10 种 | 去重 canonical speciesId |
| 博物志人 | 收藏 20 种 | 去重 canonical speciesId，不限原七物种 |
| 拼图成画 | 使用一次壁画布局 | 用户主动切换并实际渲染拼图布局，非默认预加载 |
| 守护目光 | 阅读 10 张科普卡 | 用户主动打开 10 个不同物种的科普内容；自动生成不算阅读 |

失败、取消、案例、未完成任务及仅鉴别未制卡记录均不得计入。类别未知的动态物种可计物种总数，但不得猜测植物/鸟/昆虫分类。迁移时以真实历史记录重算可推导条件，无法证明的布局使用、阅读事件不补造。首次解锁反馈幂等，减少动态模式只显示静态结果；等级和勋章不是识别置信度或保护等级。

## 3. 制卡与内容模型

### 用户流程

1. 首页点击「拍一张」立即导航现有 observe 页面并请求打开相机，不再要求点击第二个入口。权限请求遵循微信授权规则；拒绝或设备不可用时给出相册和返回选项。导航与相机启动只消费一次，返回页面不自动反复唤起。
2. 拍照/相册选择后进行鉴别，保留必要的首次隐私同意、候选、低置信度和未知提示。未知不能默认认作某物种，用户确认前不能启动生成。
3. 用户确认物种后自动进入彩绘正面与科普准备，不再要求选择“直接/艺术”两种制卡。界面清楚说明照片用于生成，沿用有效的隐私同意；没有同意不能上传。
4. 正面采用已批准的自然史参考版式：彩绘主体、物种中/学名、克制档案信息和收藏标记。背面为该次原始照片，不是共享物种插画，也不是其他用户照片；科普由详情/独立资料区域承接。AI 图仅作纪念，不能作为鉴别证据。
5. 彩绘、必要资料状态及两面资源可读取后，才进入成功揭晓和入册事务。任一真实服务失败均不保存 cards/drafts、不计统计，不以原照片静默降级。可在当前会话显式重试；退出或取消后只清理任务临时资产，不留“未完成观察”入口。

### 科普与旧卡兼容

优先填入项目可信的 family、facts、knowledge/know、habitat、season、iucn、protection 等资料，保留出处/版本。缺字段显示“资料待补充”或不展示，不杜撰；IUCN 和中国保护信息分别标注。自动科普不等于无依据生成事实，第三方资料返回失败不得伪装成功。旧卡使用 schemaVersion 区分，不重新抽工艺、不强制重新生成或覆盖原图；旧卡缺原图时如实提示，不能拿彩绘冒充原照片。

### 数据草案

- `ObservationCard`：id、schemaVersion、canonicalSpeciesId、confirmedName、可信 category、observedAt、localDate、originalPhotoAsset、artAsset、artStyleVersion、scienceSnapshot（字段、来源、版本、available/missing 状态）、note、location、createdAt。仅最终事务成功才写入收藏；每次操作有稳定 operationId 防重。
- `location`：用户主动选取的 placeId、label、必要的私有坐标及 consentAt；默认 visibility=private。没有主动操作不请求定位、不读取或上传坐标。可仅填写地点名称而无坐标。
- `CollectionPreferences`：layout=neat/puzzle、已主动使用拼图的事件。布局不修改记录或计数。
- `AchievementState`：ruleVersion、badgeId、progress、earnedAt、feedbackSeen；真实记录派生统计，行为事件按唯一 ID 去重。
- `ScienceReadEvent`：canonicalSpeciesId、首次主动打开时间；避免重复点击刷阅读数。
- `ProfilePreferences`：用户主动选择的头像、昵称和隐私设置；头像不代表已微信认证。
- `MembershipView`：价格展示与 availability=unavailable；真实权益只能来自后端已验证支付记录，客户端不得自行设置 paid/active。
- 未来 `PublicSpeciesGrant`、`FriendRelation`、`CardCopyRequest`：ownerId、viewerId、明确授权范围、pending/approved/rejected/revoked 状态。客户端不能伪造持有人或批准状态。

## 4. 页面结构

### 首页

移除探索任务和生境模块；保留自然探索氛围与真实收集反馈。中心唯一相机主入口文案为「拍一张」，点击即导航并打开相机；相册入口明确为「从相册选择」，不与拍照混淆。底栏只有首页/图鉴/我的，不增加第四个拍摄入口。

### 图鉴

只展示成功入册的真实收藏，空态引导拍下下一次遇见。提供「整齐」与「拼图」两种布局：前者规整易查阅，后者壁画式编排且所有卡仍能打开详情，无裁掉关键信息、无数据复制。重复观察在同一物种下仍能查阅，物种数和记录数分开。

足迹仅来自用户主动保存的地点，默认私有；公开界面一律显示「地点未公开」，不暴露精确坐标或可反推坐标的链接/图片元数据。不给不存在的定位记录补点，不显示假距离。没有地点时说明可自愿添加，不弹定位授权强迫完成。

### 我的

提供主动选择头像、按真实物种数提升的等级进度、自然勋章陈列与好友入口。等级阈值沿用/明确展示既有规则，不通过案例、购买、重试或重复记录增加物种数。包含隐私、帮助反馈、关于。

会员展示「月会员 ¥18」「年会员 ¥180」；对比月付 12 次 ¥216，年付省 ¥36（约 16.7%）。支付未接通前显著标注「暂未开放」，按钮不可假装购买成功，不能显示已开通、续费中、交易订单或虚构会员专属权益。会员具体权益与真实支付上线需另行确认验收。

### 好友与复制卡片

保留清晰好友入口，但未接通时说明暂未开放，不生成假好友。未来只能查看持有人明确公开的物种；公开物种不自动包含照片、笔记、地点或所有收藏。复制卡片必须持有人逐次批准，待批准不能获得卡片资源；撤销/拒绝和访问权限由服务端验证。复制来的卡片应标注来源，不冒充本人实拍，不计本人观察次数、地点和拍摄类勋章。

## 5. 隐私、失败与外部依赖

- 所有用户照片默认私有；正背导出、分享须让用户看到包含哪些照片/地点，默认不包含私密地点及坐标。不得把原图写入公共物种缓存。
- 地点选择仅在用户点击后请求系统权限；拒绝定位不影响鉴别/制卡/收藏。允许移除地点并同步清除关联足迹。帮助反馈上传日志/图片亦需用户主动选择，不带密钥或私密原图。
- 生成失败、资源读取失败、资料服务失败、存储失败需分别提供安全提示和重试入口；不泄露原始内部 URL、凭据或敏感日志。取消/页面卸载使迟到响应失效，不能在用户离开后偷偷入册。
- 入册原子性覆盖照片资源可用性、卡片记录和统计；失败不得出现半张卡或先发勋章。重试幂等，临时云资源按既有清理策略回收。
- 微信登录、CloudBase 身份与数据库/存储权限是未来真实好友互通的前提；微信支付还依赖合规商户、支付产品开通、订单服务、签名回调和退款/对账。当前文档不等于这些已开通，禁止 UI 假实现。
- 本轮仅文档，不申请权限、不改云资源、不调用生成模型、不部署、不发布、不扣款。

## 6. 测试与验收门

1. 十二名称/条件契约逐一锁定；测试边界阈值、动态物种、未知类别、重复操作、案例/失败排除、历史迁移与首次反馈幂等。
2. 一次点击拍一张仅导航/打开一次相机；拒绝授权、返回、相册、页面卸载、低动效与小屏均可继续操作。
3. 确认前不生成；成功彩绘正面和原照片背面来源正确。识别/生成/资源解码/资料服务/存储各失败及迟到回调均不入册、不记 drafts、不发勋章。重试成功只入册一次。
4. 图鉴两布局使用同一真实集合；切换不增加收藏，案例不出现；首次主动使用拼图记录一次。科普阅读按不同真实物种去重。
5. 地点未选时零定位 API/上传；拒绝授权不阻塞。仅主动保存地点进入足迹；公开/分享/导出默认无精确坐标并显示地点未公开。
6. 头像选择不伪造认证；等级只看去重真实物种。月/年价格和省 36 元计算一致；支付不可用时不存在真实开通路径。
7. 未来社交验收必须覆盖未登录、未公开、被撤销、未批准复制、跨账号越权；在真实服务部署前只验收边界说明，不宣称好友功能可用。
8. 实施后全量自动测试、原生构建、官方 WXML/WXSS、包体和原七案例哈希验证；另做真机两面卡、权限、字体放大与减少动态验证。未做的外部/真机验证单列，不以静态测试替代。

## 7. 非目标及交付边界

不新增自动定位、公开精确热点、自动分享私图、假好友/支付/积分，不扩增或改写七案例，不把生成图视作科学证明。此轮不实现商户支付、后台好友关系、复制授权交易或会员权益，也不批量重制旧卡。下一阶段需独立实施计划和批准后才修改产品代码；本次交付仅这份已确认设计文档。
