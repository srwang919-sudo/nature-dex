# 提审材料包（v0.1.11+）

## 一、小程序基本信息（建议）

- **名称**：去大自然里（以实际注册名为准）
- **简介建议**：拍下身边的植物、昆虫与鸟类，认出它，收进属于你自己的自然图鉴。照片与地点仅自己可见。
- **服务类目候选**（需在后台按实际经营选择，涉及 AI 生成内容时审核可能要求补充资质）：
  - 工具 → 图像/图片处理
  - 教育 → 科普知识
  - 如类目选项中含「人工智能」相关，建议同时勾选并准备相应说明
- **标签建议**：自然观察、物种识别、图鉴收藏、AI 艺术

## 二、功能路径说明（供审核员复现）

| 步骤 | 操作 | 预期 |
|---|---|---|
| 1 | 打开小程序 → 探索页 → 点「拍一张」 | 拉起相机；也可从相册导入 |
| 2 | 拍摄或选择一张植物/昆虫/鸟类照片 → 点「开始识别」 | 首次需同意上传所选照片用于鉴别；返回识别结果与置信度 |
| 3 | 在候选里点选物种 → 「确认物种并制卡」 | 生成艺术卡面（AI 生成，页面标注「卡面插画由 AI 生成 · 非实拍照片」） |
| 4 | 收入图鉴 → 底部「图鉴」tab | 看到收藏卡片；可搜索物种名/学名/地点；切换「整齐 / 卡架」 |
| 5 | 「旅程」tab | 地图化显示走过的时间轨迹与地点；点击节点显示地点 |
| 6 | 「我的」tab | 观察统计、等级、勋章（图形为 AI 生成）、笔记 |
| 7 | 「好友」tab | 需主动连接服务；未配置前显示未开放说明 |

**测试账号**：无需注册登录，使用微信身份即可；审核员用自己的微信打开即可完整体验基础功能（拍照 → 识别 → 制卡 → 图鉴）。

## 三、需要说明的合规点

1. **AI 生成内容**：卡面插画与勋章图形由 AI 生成。已在卡片详情页、揭晓页、关于页标注「AI 生成」，并声明其非鉴别依据。
2. **位置信息**：不自动定位；仅在用户主动点击添加地点时调用 `chooseLocation`，用途已在 `app.json` 声明。
3. **第三方**：百度 AI（图像识别）、腾讯混元（艺术生成），已在隐私指引中列明。
4. **未开放功能**：会员购买、好友服务、实体卡打印在服务端配置完成前均不可实际使用，界面明确说明未完成配置，无误导性购买按钮。
