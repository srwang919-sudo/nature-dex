# 无法确认授权素材清理设计

## 目标

删除所有无法确认商用授权的内置案例照片、物种插画、徽章、首页大图和字体，同时保持小程序界面可用、不泄露用户私人照片。

## 方案

采用“删除旧素材 + 本地绘制中性占位”：

- 首页大图替换为 WXML/WXSS 的太阳、山形与叶片构图，无外部图像依赖。
- 内置案例卡改为空集合，不以占位照片伪装真实观察。
- 本地物种插画映射改为空，由既有文字/线稿降级逻辑处理。
- 十二个成就共用一张项目自绘的中性叶片 PNG，不冒充物种徽章。同一 PNG 也作为微信分享安全图，避免默认截图带出私人卡面。
- 图形源 SVG 仅由基础几何路径、项目色板和项目文案组成；PNG 是该 SVG 的机械导出。

## 数据与隐私边界

只处理 Git 跟踪的静态发布素材。不扫描、移动或删除微信用户数据目录、拍摄临时文件、私有云存储或导出备份。删除前将精确文件复制到仓库外的专用备份目录，并保存相对路径、字节数和 SHA-256。

## 验收

- 旧素材在工作树、Git 跟踪结果和发布包清单中全部缺席。
- 全仓不再存在对旧照片、插画、徽章、首页 JPG 和字体的运行时引用。
- 首页保留自然博物气质、明确拍摄主操作、低动效支持与语义标记。
- 中性叶片 PNG 可用于徽章占位和分享预览，且测试记录其来源与尺寸。
- `npm test` 和 `npm run build:weapp` 通过。
