# 私人自然博物馆：UI/UX Audit 与执行设计

依据用户 2026-09-23 完整附件（1026 行，已读）直接执行，不再次逐项确认。原三入口与明亮童趣方向由本 brief 取代。平台仍为现有原生微信小程序，不改写业务栈。

## 当前审查

1. `tab-model` 只有首页/图鉴/我的，缺中心发现与旅程。
2. 首页由拍照按钮和今日收集组成，缺最近/过去，CSS山丘并非用户自然世界。
3. 全局样式两套覆盖、旧橙色主按钮/大圆角/多种绿色并存，缺统一token源。
4. 收藏已有真实数据、两列与卡架，可保留逻辑，收敛重复标题和卡外名称。
5. 揭晓已具失败不进入、按住/继续、低动效，应保留数据状态机而替换装饰。
6. 卡背V2必须仍为原照片；旧卡无插画不能把中性叶片叫手绘版。
7. 12种勋章共用一个叶片，难以区分；使用原创几何章面和中文短标，不恢复无权素材。
8. 科普缺字段提示过多，应一处“资料暂缺”，有资料显示可见来源；不制造知识。
9. 我的/设置存在已实现云后端与“尚未连接”静态UI脱节，应接真实服务并诚实显示失败。
10. setup旧入口已退休，正式导航不应展示；保留兼容路由但不恢复素材上传。

保留：observe识别确认/同意/安全错误、严格艺术生成、collectible单面翻转、真实收藏过滤、卡架手势、隐私投影、照片导出、主动阅读、12勋章条件、账户清理。
重构：导航、home、journey新增页、library信息层级、observe/reveal外观、profile/徽章与settings服务入口。

## 参考锁与决定依据

Refero三角度检索均返回NO_SUBSCRIPTION，未伪称见过屏幕。替代依据为用户完整视觉brief、现有产品结构、Refero typography/craft-details及Impeccable product参考；不引入外部样例素材。

| 决定 | 来源与角色 | 保留边界 |
| --- | --- | --- |
| 纸色+墨色，绿只用于动作/选中 | 用户颜色系统 | 不铺满绿，不用金色普通按钮 |
| 今天/最近/过去 | 用户首页结构 | 仅真实记录，不伪造城市/附近数量 |
| 两列收藏+卡架 | 用户新brief与已批准卡架 | 正面艺术与背面原照不互换 |
| 系统sans+学名serif italic | 用户字体规则、typography参考 | 不下载字体，正文不手写 |
| 一处主动作与独立状态/错误 | product/craft-details | 保留可取消、可重试和明确同意 |
| 原创几何徽章 | 用户权利撤回+珐琅章方向 | 标识是章面，不假装物种水彩 |

场景：用户白天散步后在手机上翻看自己的收藏，纸色保持户外可读，艺术卡成为视觉主角。策略为克制中性色，分类低饱和色只用于标签；金色仅真实奖励。

系统字体；正文32rpx、辅助26rpx、导航24rpx、章节36rpx、标题48rpx；学名Georgia/serif italic。间距8/16/24/32/48/64rpx。艺术卡16rpx、按钮22rpx、面板24rpx；1rpx线，无大影。触控>=88rpx。变换/透明度180–240ms，低动效零过渡。安全区底部留白，不锁用户字体缩放。

## 数据与页面

`buildMuseumTimeline(cards, now)`只输入realCards，稳定排序，过滤无效/未来日期；输出today/recent/memory、首遇、实际季节分组。没有过去记录则邀请保存第一次遇见。回忆必须真实同月日或真实往季；不将七种资料目录变成用户收藏。

探索：日期、简短问候、主视觉选最近真实艺术卡，无卡为明确“你的自然世界从这里开始”空画框；不再模拟复杂CSS插画。今天展示当天记录；最近展示其余近期记录；过去展示可验证的纪念。中心发现直达现有source=camera单次启动路径，相册独立入口。

旅程：按年月/季节排真实卡；主动地点仅在本机可见设置开启时显示，继续不上传坐标。无地区数据不做地图/距离。地区集合只由主动地点聚合，不声称地域完整物种总数。重复观察显示真实次数/不同日期/季节，不推断幼鸟或筑巢，不改变工艺等级。

图鉴：两列主视图，真实物种总数为轻提示；整齐/卡架可切换。保留卡面同一母版，强化图片65–75%、名称/学名/编号可读。缺图留明确资源错误，不替换成原图或案例。

发现：空闲相机全屏化，候选/确认/同意成为分阶段操作，不隐瞒处理方。未确认不制卡；成功生成并保存后才发现动画。线稿感只能用已生成图的克制单次去饱和→彩色过渡，不宣称是真实识别轮廓。低动效显示最终卡+继续。

我的：真实等级/勋章、头像、笔记、隐私与服务。会员调用natureMembership，只有服务端query确认权益；未配商户显示准确不可用原因。好友调用natureSocial，邀请/接受/选择明确共享/复制请求与审批；纪念副本不计发现。没有公共动态fixture。
