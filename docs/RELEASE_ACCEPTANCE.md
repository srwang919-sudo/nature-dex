| 鉴别 | 未配置、可确认、低置信度、未知、超时 | 未配置明确 unavailable；低置信度须确认；未知保留草稿；超时可重试；不虚构置信度 | 云函数日志和界面截图 |
| 照片导出 | 正常、低清晰度、解码失败、文件删除、离页 | 正常导出完整照片和对应插画；低清晰度提示；其余情况不产生粉红、空白、旧缓存或成功提示 | 相册成品与失败录屏 |
| 分享 | 资料分享与含照片导出 | 资料分享无私照、笔记、卡号、地点或来源；含照片导出有明确确认 | 分享接收端截图 |
| 图生图 | 同意、成功、超时、拒绝 | 每次上传前单独同意；生成只作装饰；失败保留原卡；供应商错误不泄露凭据 | 同意记录、云函数日志、截图 |

| 删除 | 本地、云端、派生图、断网 | 删除请求覆盖照片、生成图和记录；失败显示待重试而不假称完成 | 存储核对、离线/重连录屏 |
| 安全与隐私 | 权限、密钥、访问控制 | 凭据只在云函数密钥管理；私有照片不可被他人直接读取；隐私指引与实际一致 | 配置截屏（打码）与账号测试 |
| 性能与包体 | 低端 Android、冷启动、资源 | 首屏可交互、动画不掉帧到不可用；主包符合微信当前限制；资源清单说明大文件来源 | 真机录屏、构建包报告 |
| 编译回归 | JavaScript、WXML、WXSS、原生测试 | 全量 Node 检查、现有 native 测试、官方 WXML/WXSS 编译全部通过 | 命令输出存档 |

- 正反面生成统一175秒客户端总截止时间、5秒状态查询间隔；单次客户端等待最多15秒。客户端超时不代表服务端失败，之后仅查询相同任务/物种状态，不重复创建任务。服务器180秒边界附近未完成显示“仍在生成”，可显式重试同一键。
- 物种插画首次并发的processing/generating继续轮询；failed和not_found分别呈现。页面隐藏/卸载/换观察使生成token失效；迟到结果不保存、不导航，已有后台生成只可由显式重试恢复查询。

- 私有和公共函数在统一canonical物种验证之后构造prompt；别名映射同一公共缓存，映射外合法动态名称继续支持。
