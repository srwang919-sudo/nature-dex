# 百度识别与确认后科普：已确认设计

用户已确认：百度是唯一识别服务；百炼只生成用户已确认物种的科普，万相只在明确授权后生成手绘卡背。此前原生和Taro双实现不一致，唯一发布源固定根app与native。Taro仅为历史实验，不得使用build:weapp暗示其输出是当前发布版。

方案选择：不在客户端持有凭据，不直接调第三方；使用CloudBase云函数服务端交换百度access_token并调用animal/plant。通用模式并行两路专业接口，结果保留provider、候选及分数；未识别、接口失败、低置信均不伪造确定性。0.86只是未校准的候选展示阈值，仍需用户确认；候选分值非科学准确率。未知物种保留名称，不强行归到七种。

照片拍下只保存本地。每次识别前界面说明上传CloudBase私有存储并转交百度，用户确认后上传；上传关联当前草稿，取消/切换使迟到响应失效。云端用OPENID与文件归属记录校验私有访问，不信任客户端任意fileID或云路径。百度/百炼密钥只从环境变量读取，不查看新密钥；删除旧硬编码后仍须用户吊销旧凭据。

确认物种生成本地卡不依赖百炼。科普及手绘各自提供明确同意按钮；reveal入册不自动触发。服务端再次校验确认标志和同意，生成任务绑定OPENID与观察；获取结果不返回永久公开地址。CloudBase存储和数据库规则需由用户控制台部署为仅创建者读写，云函数自身也校验。未配置或规则拒绝时保留本地卡与线稿。

示例与个人页面必须显式标识；示例不进入真实收藏统计，零收藏显示0，不显示nash/157/假订阅额度。自动云同步不得绕过用户同意上传私密笔记。

验证：离线模拟百度token/animal/plant、低分/未知/失败/跨用户fileID、无授权不上传不调用、源码无密钥字面量、唯一发布入口；全部tests/*.cjs与原生构建/官方静态编译。没有真实凭据、部署或云端校准证据时只报告本地通过。不开账号、不配置控制台、不上传。
