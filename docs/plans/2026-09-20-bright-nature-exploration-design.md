# 纯 C：明亮童趣自然探索 UI 设计说明

状态：用户已选择纯 C 方向；本文件是待主控批准的可执行设计规范。本轮只新增文档，不修改应用代码、图片、案例资料、生产配置或云资源。项目非 Git 仓库，不创建提交。

## 产品场景与边界

用户在白天散步、郊游时，用手机拍下花鸟昆虫，再回到家翻阅自己收藏的卡片。界面像一本明亮的自然探索手册，轻松、有发现欲，同时确保户外可读、操作可信，不做低龄游戏或贴纸拼贴。

产品 register 为 product。人格仍是自然、珍藏、可信。纯 C 不混入旧水墨山水首页的肃静气质，不引入深色霓虹、杂志封面、玻璃模糊或重金属游戏大厅。

保留唯一原生发布源 app.js 与 native。拍摄、单独鉴别、候选确认、原图或艺术制卡、严格失败不保存、揭晓、翻面、入册的业务边界不变。生图429等服务问题独立处理，视觉更新不能将失败伪装为成功。

## 已检查的现状

- home：山水背景、中央深绿拍摄按钮、两张当季推荐。
- library：章节进度、类别与工艺组合筛选、收藏卡网格、七张案例横排。
- profile：真实本地统计、进度、徽章、笔记与低动效设置。
- navigation：发现/收藏/我的三项。拍摄目前只在首页中心。
- collectible：独立收藏卡母版，实拍大图、编号、工艺、底部中文名/学名/五星位。该正面结构不重做。
- library 当前文案出现9格，profile文案为7种。实施时必须以真实章节模型检查分母，不能只为画面好看制造不可完成的进度。

## 视觉系统

色彩策略：温暖中性色为大面积基底，四个有语义的自然色作有限强调。每屏70%以上为纸色与留白，最多一个主行动色块、两个辅助色块。

| 角色 | 小程序兼容色值 | 用途 |
| --- | --- | --- |
| 纸张底色 | #FFF8E8 | 页面背景，暖而不黄 |
| 提亮纸面 | #FFFCF4 | 工具栏、必要的信息面板 |
| 深青绿 | #183F36 | 正文、标题、线性图标 |
| 辅助文字 | #52635A | 说明、次级标签 |
| 苔藓绿 | #647B42 | 已完成任务、自然主题徽章 |
| 湖蓝 | #3C7F92 | 生境信息、观察知识标识 |
| 陶土橙 | #C45431 | 唯一主拍摄入口、主要确认动作 |
| 少量暖黄 | #F2CF70 | 新解锁、星形细节，搭配深绿文字 |
| 纸边线 | #DED8C6 | 细分隔、弱边框 |
| 错误文字 | #A83B30 | 可读错误，不能仅靠颜色表达 |

设计稿可用OKLCH调节明度，落地保留已核对对比度的十六进制值以兼容微信基础库。橙按钮用浅纸文字；黄底、浅蓝底、浅绿底均用深绿文字。正式实现需实测正文对比度至少4.5:1、非文本关键控件至少3:1，若不达标先加深文字而非加阴影。

### 字体、尺寸和间距

- 中文使用系统无衬线，不新增远程字体。童趣来自插画、形状和反馈，不把手写字体用于正文或按钮。
- 以750rpx视口为基准：页面左右32rpx；区块间32至40rpx；局部间隔12/16/24rpx。
- 页面标题44rpx/600，区块标题34rpx/600，正文28rpx，辅助24rpx；长科普行高1.55。正文不压成小字以容纳装饰。
- 常规按钮至少88rpx高，触控目标至少44px。主面板圆角28rpx，按钮24rpx，标签胶囊；实体收藏卡仍保持既有卡框和比例，不套大圆角。
- 仅主要悬浮导航使用柔和短阴影，无黑描边硬位移影。内容以开放排版、纸面分隔组织，不层层嵌套卡片。

### 插画与图标

使用手绘 gouache 不透明水粉：块面柔和、边缘轻微笔触、形态清楚，有自然观察感。可出现叶片、野花、望远镜、观察手册，但一屏装饰插画总面积不超过约四分之一，不覆盖文字与实拍照片。

新增主题插画需另建独立命名文件；原有七张案例数据及 assets/images 中对应资源逐字节保留，仍标识“案例，不计收藏”。不得把案例图登记公共AI缓存，不复用用户私图作装饰。

导航与状态图标采用同一套本地线性图标或WXSS图形，圆端、统一粗细，不用Unicode或emoji拼接。没有新插画时先用少量本地形状占据明确装饰区，不伪称已经完成手绘资源。

## 导航与页面范围

### 导航

保留发现、图鉴、我的三个页面目的地，并在底部导航视觉中心增加抬升陶土橙“拍摄”行动按钮。建议从左到右为发现、图鉴、拍摄、我的，四个等宽命中区，拍摄按钮向上抬16rpx、直径112rpx。按钮独立于页面选中态，不把它伪装为第四个持久页面。

按钮点击进入现有observe入口，不自动上传、不自动请求鉴别。按钮下始终有“拍摄”文字。底栏内容高112rpx，加设备安全区；页面底部预留至少底栏总高再加24rpx，避免遮住末行。进入相机、制卡、揭晓时不让底栏争抢主要动作。

### 发现首页：一眼知道下一步

自上而下：简洁品牌/短问候；小幅水粉自然场景；“今天去发现一点新鲜事”主标题；一张探索任务纸签；今日真实收集缩略图；生境探索入口。

探索任务为本地建议，不是定位或实时推荐。首发只用可由现有记录验证的目标：

- 尚无收藏：拍下并收录第一次遇见，0/1。
- 已有收藏：本章发现一种尚未收录的物种，按章节真实集合计算。
- 已达章节目标：展示“本章已完成，继续记录新的遇见”，不生成无法完成的假任务。

任务一主一次，不堆日常任务、签到倒计时、奖励弹窗。首要按钮“去拍摄”，次要入口“从相册选择”。任务本身不强行切换识别类别、不保证能在附近遇见某物种。

今日收集仅统计当地日期已成功入册的非案例卡，空态“拍下下一次遇见”。“附近”改为明确的“探索生境”入口承接现有nearby，不显示假距离、实时天气或未请求的位置。

### 图鉴：收藏价值与清晰进度

顶部为“我的图鉴”和真实物种数，章节进度像观察手册页签。徽章只在真实达成时着色，未解锁用浅纸轮廓且显示条件，不用大锁刺激付费。

类别筛选与工艺筛选保留组合能力，选中态深绿文字/浅绿色底并带标记，不能仅靠颜色辨别。收藏母版继续用现有collectible，不改变实拍大图、编号、工艺徽标、信息栏和五星槽位。

章节按物种去重，重复观察增加记录数但不虚增物种/章节经验。案例区独立放在真实收藏之后，原七张内容、资产与示例身份不变。案例不点亮徽章、不影响任务。

### 我的：成长记录而不是伪积分商城

身份维持真实本地身份，不暗示已登录或已云同步。将徽章陈列、探索经验、观察天数和笔记形成一张观察者记录页；减少平铺大数字和重复统计。

经验定义为本地可解释的收藏进度，不新建消费积分：本章每个真实、首次收录的目标物种=1经验；经验上限为章节可发现物种数。沿用已有buildProfile/getBadges计算，不用视觉重构暗自改奖励规则。若既有模型与该定义冲突，实施前交主控确认，不混用“7种”和“9格”。

展示“探索经验 3/7”时，必须能由保存卡推导出3，不使用固定演示值。徽章配短条件，如“收录首种物种”；不新增假的订阅、好友、连续签到收益或兑换入口。笔记仍来自用户实际笔记；无笔记时给简短行动入口。

### 拍摄、鉴别、揭晓与详情

只同步颜色、按钮、提示层级与纸张材质，业务路径不增加步骤。识别中使用明确状态和取消入口；429等失败保持可读，不靠一张开心插画掩盖失败。

成功揭晓使用一束短光、一点暖黄碎纸形状或徽章压印感，最多一次、300至500ms，不持续撒彩纸。收藏成功反馈“已收入图鉴”及真实物种进度；重复物种写“又一次遇见，记录 +1”，不写“新物种”。卡片3D跟手和短按翻面保持现有交互，不能因装饰增加镜像、误触或滚动冲突。

卡背科普与生成水彩属于卡面内容，不由外围UI替换。原有失败不保存和主动原图规则保持，UI不得擅自降级。

## 动效、可访问性、错误和空态

- 常规交互180至220ms ease-out，只有transform/opacity，禁止页面进入逐项弹跳。
- 拍摄入口不呼吸、不抖动；用户按下才轻微缩放，松手回位。
- 减少动态效果关闭倾斜、扫光、碎纸和位移，成功状态直接显示文字/徽章；关键功能仍全部可操作。
- 375/390/430px宽及大字体检验；长中文名换行不盖住保护说明；底栏适配安全区。
- 错误、选中、完成状态同时有文字/图形，颜色不是唯一信息。未知、零收藏、无笔记、无候选、制卡失败各有独立且诚实的空态。

## 验收门

1. 首页无需滚动即可理解“拍摄→鉴别→制卡”，主要操作不超过原流程步骤。
2. 真实零收藏状态所有经验/任务/徽章为零或未获得；七张案例可查看但绝不计数。
3. 同种重复卡只增加记录数；章节分母与可发现种数一致。
4. 原正面收藏卡结构、照片、保存状态与五星数值没有被视觉重构修改。
5. 低动效、字大、长名、小屏、安全区和错误状态无裁字/遮挡。
6. 保留原卡片交互、严格制卡、分享隐私、导出尺寸等自动测试；全量Node测试、原生build与官方WXML/WXSS编译通过。
7. 对新旧7张案例资产做hash对比；确认未触及生产云资源。
8. 主控审阅真实页面截图后批准，才能宣称C方向已经落地；本文档本身不代表UI已实现。
