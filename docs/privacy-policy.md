## 一、处理的信息与用途

| 信息 | 触发和用途 | 存储/传输边界 |
|---|---|---|
| 拍摄或相册选择的照片 | 主动选择照片并同意识别后，用于鉴别物种和制作卡片 | 所选照片上传腾讯云私有存储并发送百度图像识别；制卡完成后原图作为卡背关联保存 |
| 卡片、物种确认、生成任务与额度记录 | 确认物种、生成/收藏和使用额度时 | 本机保存显示副本；相关卡片、观察、任务及额度记录也由云端按用户身份保存，并非全部仅在本机 |
| 手选地点 | 主动选择地点，记录观察足迹 | 可能含地点名称和经纬度，保存在本机；当前公开分享/打印投影不展示精确位置。地图/选点使用微信平台能力，需对应权限 |
| 头像、笔记与本机偏好 | 主动编辑个人展示与记录 | 当前自选头像、私人笔记和显示偏好保存在本机；本机导出可能包含这些内容，发送前请自行检查 |
| 微信 OpenID | 使用云服务时确认数据归属、权限与账号状态 | 是可关联微信用户的标识信息，应作为个人信息妥善处理；不是匿名数据 |
| 产品使用事件 | 拍摄、识别结果、制卡、收藏、会员页面或打印等操作时 | 客户端批量发送事件名称、时间及业务状态等属性；云端关联 OpenID，用于运行与使用情况分析，不应称为匿名统计。当前正常调用不发送原图、私人笔记或精确坐标作为事件属性 |
| 好友、分享与获赠授权 | 主动连接好友、分享、申请/批准复制或授予打印权时 | 云端保存关系及授权记录；对方可见你明确分享的物种摘要。获赠打印须单独符合源卡及授权规则 |
| 会员订单与支付状态 | 仅在实际开放会员支付且用户主动购买时 | 微信支付和本项目云端按交易流程处理订单、支付/退款状态；不由本项目采集银行卡密码 |
| 打印草稿/履约记录 | 主动制作实体卡并提交相关流程时 | 后端按本人或获赠打印授权读取卡面/原照资源；生产运营者仅在授权范围内处理。正式履约/供应商数据范围须启用前补充 |

当前代码不读取通讯录或聊天内容，不后台自动定位。所选照片本身可能含人物、地点或其他敏感内容，上传前请确认愿意用于所选功能。

| 服务 | 用途 | 当前发送内容/时机 |

原照片默认私有，但“仅本人永远可见”并不准确：明确授予获赠卡打印权后，受控打印服务/已授权运营者可能访问相应原图卡背。普通好友列表/物种摘要不会直接公开原图或精确坐标。

## 三、保存、恢复与删除

- 保存期限、服务器地域、备份周期及各类记录具体保留标准：**待运营主体确认并补充**。
- 云端恢复默认关闭，须独立同意；关闭恢复不等于删除云端记录。
- 删除卡片时先记录删除意图，再移除本机卡片；如果本机无法保存删除意图，将提示失败并保留卡片，避免无记录丢失。
- 云端清理成功后才视为云端删除已确认；断网或服务失败会保留重试任务，可在设置查看。卸载会移除本机重试记录，清理尚未成功时应先完成重试或联系运营者。
- 清除本机数据和申请清除云端个人数据是不同操作。云端清除可能分批执行；依法/业务所需保留的交易记录范围和期限须由运营主体核定，不作“所有数据立即彻底删除”的承诺。
- 已经审核并作为公共物种插画发布的独立衍生图可能继续存在，不会因删除某一私人观察而一并删除。
