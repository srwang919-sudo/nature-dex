# 本地完整迁移设计（已批准）

用户确认独立 AppID、名称和主体；本轮仍只本地开发，不上传或生成手机预览。

A 收藏可靠性：版本4多草稿迁移旧nature.draft.v3，activeId记录最近草稿；未知与未入册卡保留恢复入口，新照片创建新草稿。单项删除只删除不再被其他记录引用的本地文件，失败进入可重试清理队列。首页按七物种去重展示，类别与工艺组合筛选，重复卡出现在最近记录。完整详情使用现有七物种全部facts/know/stats/season/family。

B 分享与打印：微信分享仅传公共物种资料ID，接收端不会获得原卡ID、原照片路径或私人笔记。包含自己照片的图片仅经显式导出操作本地生成、再保存相册。保护物种默认正背合图。打印使用63.5×88.9mm裁切、3mm出血、300dpi，外框821×1121、裁切750×1050，输出PNG；PDF和下单不伪造。用小程序原生Canvas生成静态图片，不改变3D组件。

C 附近与个人：静态生境、季节、观察礼仪，不采集真实位置、不聚合他人坐标、不显示假距离。个人页提供最近记录、笔记、草稿、JSON导出、二次确认清除、低动效。使用本地CSS线性图标。清除所有本产品本地照片/数据，不碰其他应用数据。

边界：真实识别和好友赠送只定义接口契约与未开放说明。没有公开广场、假订阅、假好友按钮。保留现有工艺概率、单快门、翻面锁与卡背阅读。
